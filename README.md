#                                           Nokia EDA – First Steps

Intent resources applied to the Try EDA Digital Twin (3x SR Linux 26.7.1: leaf1, leaf2, spine1) running in GitHub Codespaces, managed from VS Code with the Nokia EDA extension.

- `fabric/myfabric-1.yaml` – eBGP underlay + EVPN overlay (Fabric v1)
- `services/vnet-vlan10.yaml` – L2 EVPN-VXLAN service on VLAN 10 (VirtualNetwork v2)

Note: validated with fabrics.eda.nokia.com/v1 and services.eda.nokia.com/v2; older docs show v1alpha1/v1 field names.
